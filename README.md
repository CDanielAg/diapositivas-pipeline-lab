# Stochastic Pipeline Lab

Interactive React slide deck and CI/CD failure simulator inspired by technical architecture diagrams.

## Features

- Ten navigable presentation modules
- Interactive CI/CD pipeline with per-stage probabilities
- Monte Carlo simulations for N = 100, 500 and 1000
- Convergence chart and experimental evidence matrix
- Markov, Bayesian and Weibull modeling overview
- Keyboard navigation and JSON snapshot export

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build

```bash
npm exec vite build
```
